# Hassouni store — PHP + MySQL edition

A port of the Next.js store for ordinary shared hosting (cPanel, Apache/LiteSpeed,
PHP 8.1+, MySQL 5.7+ / MariaDB 10.3+). Same URLs, same pages, same business rules,
same texts. The original React client components (cart, checkout, order forms,
live chat, PWA) are reused as "islands"; everything else is server-rendered PHP.

```
php-hosting/
  site/            ← upload this folder's contents to public_html (see دليل-التثبيت.md)
    index.php      front controller (routes, same URLs as the original)
    install.php    one-time web installer (delete after use)
    app/           code, SQL, data — never served (.htaccess + rewrite rules)
      lib/         db, http, auth, i18n, ui, domain rules, services
      actions/     the server actions as POST /_action/<group>.<name> endpoints
      views/       store and admin pages
      data/        texts, guides, icons, artwork exported from the TypeScript sources
      sql/         schema.sql (tables) and seed.sql (catalog for a fresh install)
    assets/        app.css (Tailwind), islands.js (React components), fonts
  islands/         bundle entry + shims (next/link, server actions → fetch, shared cart store)
  build/           export-data.tsx, build-css.mjs, package.sh
  tools/           make-seed.php (seed.sql from a PostgreSQL database)
  tests/           the original e2e suites, run against the PHP site
```

## Build

From the repository root:

```bash
bash php-hosting/build/package.sh      # → php-hosting/dist/hassouni-php-store.zip
```

`package.sh` exports the dictionaries/guides/icons from `src/`, bundles the islands,
compiles the CSS and zips `site/` (without `app/config.php`). Re-run it after changing
texts or components in the Next.js sources.

## Data

- Fresh install: `app/sql/schema.sql` + `app/sql/seed.sql` (generated by
  `tools/make-seed.php` from a Postgres DB built with the original migrate/seed/content-update scripts).
- Moving an existing store: the installer copies every table from the original
  PostgreSQL (Neon) database with PDO PostgreSQL. Column names are identical; Argon2id
  password hashes, wallet ledgers, files and the VAPID keys carry over unchanged.
