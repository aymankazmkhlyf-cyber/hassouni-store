# دليل تثبيت متجر حسوني على استضافة PHP و MySQL

هاي النسخة تشتغل على أي استضافة مشتركة بيها cPanel: PHP 8.1 أو أحدث، و MySQL 5.7+ أو MariaDB 10.3+.
ما تحتاج Node.js ولا أي برنامج إضافي.

---

## قبل ما تبدي

1. **لازم الموقع يكون على دومين أو سب دومين كامل** (مثل `store.example.com` أو `example.com`)، مو داخل مجلد فرعي مثل `example.com/store`.
2. **لازم يكون عندك SSL (https)**. أغلب الاستضافات تعطيه مجاناً من cPanel ← SSL/TLS Status ← Run AutoSSL.
3. من cPanel ← **Select PHP Version** (أو MultiPHP Manager) اختار **PHP 8.2 أو 8.3**، وتأكد هاي الإضافات مفعّلة:
   - `pdo_mysql`, `openssl`, `mbstring`, `curl`, `sodium`
   - وإذا تريد تنقل بياناتك من الموقع القديم: فعّل `pdo_pgsql` أيضاً.

---

## الخطوة 1: سوّي قاعدة البيانات

1. cPanel ← **MySQL® Databases**.
2. بقسم **Create New Database** اكتب اسم (مثلاً `store`) واضغط **Create Database**.
3. بقسم **Add New User** اكتب اسم مستخدم وكلمة مرور قوية واضغط **Create User**. احفظ الاسم وكلمة المرور.
4. بقسم **Add User To Database** اختار المستخدم والقاعدة، اضغط **Add**، وبالصفحة اللي تطلع حدد **ALL PRIVILEGES** واضغط **Make Changes**.

> انتبه: cPanel يضيف بادئة للأسماء، مثل `user123_store`. استخدم الاسم الكامل كما يظهر.

---

## الخطوة 2: ارفع الملفات

1. cPanel ← **File Manager** ← افتح مجلد **public_html** (أو مجلد السب دومين).
2. اضغط **Upload** وارفع ملف `hassouni-php-store.zip`.
3. ارجع للمجلد، اضغط على الملف بالزر الأيمن ← **Extract**.
4. تأكد إن الملفات (`index.php`، `install.php`، مجلد `app`، مجلد `assets`...) صارت **مباشرة داخل public_html**، مو داخل مجلد ثاني.
5. فعّل **Show Hidden Files** من Settings وتأكد إن ملف `.htaccess` موجود.
6. احذف ملف الـ zip بعد الفك.

---

## الخطوة 3: شغّل المثبّت

1. افتح بالمتصفح: `https://دومينك/install.php`
2. أول قسم يفحص الاستضافة. كل شي لازم يكون عليه ✓ أخضر (الاختياري ممكن يكون أصفر).
3. اكتب معلومات قاعدة البيانات من الخطوة 1.
4. اختار البيانات:
   - **متجر جديد**: كل الأقسام والخدمات والأسعار وطرق الدفع (مع باركود سوبر كي) جاهزة.
   - **نقل بياناتي من الموقع القديم**: الصق رابط `DATABASE_URL` من Netlify (Project configuration ← Environment variables ← DATABASE_URL ← اضغط على العين حتى يبين). ينقل الزبائن والطلبات وأرصدة المحافظ والتقييمات والمحادثات والصور. الرابط يُستخدم مرة وحدة وما ينحفظ.
5. اكتب بريد وكلمة مرور المدير (12 حرف أو أكثر).
6. اختياري: توكن بوت التلكرام ومفتاح Resend للإيميل. تكدر تضيفهم بعدين من ملف `app/config.php`.
7. اضغط **ثبّت الموقع**.

> **مهم جداً:** بعد ما يطلع "تم التثبيت بنجاح"، **احذف ملف `install.php`** من File Manager.

---

## الخطوة 4: تأكد إن كلشي شغال

- افتح `https://دومينك/ar`. لازم تطلع الرئيسية.
- افتح `https://دومينك/ar/admin/login` وادخل بحساب المدير.
- سوّي طلب تجريبي: أضف خدمة للسلة، أكمل الطلب، وشوفه بلوحة التحكم.
- افتح `https://دومينك/app/config.php`. **لازم يطلع Forbidden (403)**. إذا طلعت صفحة ثانية، راسلني قبل ما تفتح المتجر للناس.

---

## ربط تلكرام (إشعارات الطلبات على تلفونك)

1. بتلكرام افتح **@BotFather** ← `/newbot` ← اختار اسم ← انسخ الـ Token.
2. File Manager ← `app/config.php` ← Edit ← الصق التوكن بين علامتي التنصيص بسطر `'telegram_bot_token' => ''` ← Save.
3. افتح البوت مالتك بتلكرام واضغط **Start**.
4. لوحة التحكم ← **الدعم المباشر** ← اضغط **ربط تلكرام**.

---

## تحويل الدومين من Netlify

بعد ما تتأكد إن المتجر شغال على الاستضافة:
- إذا عندك دومين: غيّر الـ DNS (أو الـ Nameservers) حتى يأشر على الاستضافة الجديدة.
- اللي ثبّتوا تطبيق المتجر من الرابط القديم (netlify.app) يحتاجون يفتحون الرابط الجديد ويثبّتوه مرة ثانية.

---

## ملاحظات

- **النسخ الاحتياطي:** cPanel ← Backup ← نزّل نسخة من قاعدة البيانات أسبوعياً.
- **الصيانة اليومية** (حذف البيانات القديمة حسب سياسة الخصوصية) تشتغل تلقائياً لما تفتح لوحة التحكم.
- **نسيت كلمة مرور المدير؟** cPanel ← Terminal:
  `php tools/create-admin.php بريدك "اسمك" 'كلمة-مرور-جديدة-طويلة' admin`
- **رسالة "حدث خطأ غير متوقع":** cPanel ← Errors (أو ملف `error_log` داخل public_html) يبين السبب.
- **ملف `app/config.php`** بيه كلمة مرور القاعدة والمفاتيح السرية. لا ترسله لأحد.
